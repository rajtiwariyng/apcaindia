### Source analysis
- WP dump: 243 published `post` rows (2017-09 → 2026-11). Revisions, attachments, 24,057 `cmsmasters_view` drafts etc. ignored.
- 4 WP slugs already existed in `tbl_blog` → **skipped** (existing rows untouched).
- 6 posts have no featured image in WP; 51 had no category (→ `Uncategorized`); 4 had several categories (→ first one).

### Field mapping
| WP | `tbl_blog` |
|---|---|
| `post_title` (entities decoded) | `title` |
| `post_name` (sanitised like the admin: `[A-Za-z0-9-]`, lowercase) | `slug` |
| `post_content` (Gutenberg comments stripped; paragraphs added where WP relied on auto-paragraphing) | `description` |
| first `category` term | `category` (case-insensitive match to existing names) |
| featured image (`_thumbnail_id` → `_wp_attached_file`), downloaded | `image` (filename `uniqid_name`, same scheme as the admin) |
| attachment alt text (cut to 150 chars at a word boundary: 1 post, WP id 23846) | `img_alt` |
| `rank_math_title` / `rank_math_description` / `rank_math_focus_keyword` | `metatitle` / `metadesc` / `metakeywords` **and** a `tbl_seo` row `blog/<slug>` (the admin does the same on save; the front end reads metas from `tbl_seo`) |
| `post_date` / `post_modified` | `created_at` / `updated_at` |
| — | `status = 0` (hidden until reviewed), `uniqueid` generated like `random_unique_id()` |

### Schema impact
**None.** No missing fields required an `ALTER`. Two limits were handled in data instead:
- `tbl_blog.description` is `latin1`; 11 posts contain `₹` / `●`. Stored as HTML numeric entities (`&#8377;`, `&#9679;`) — renders identically.
- `img_alt` is `varchar(150)`; one value truncated (see above).
Not imported (no target column; WP-only): excerpts (none exist), tags, WP post IDs, multi-category links.

### Files
- `docs/import/import_wp_blog.php` — idempotent importer (dry-run default, `--commit` to write, transactional, insert-only).
- `docs/import/backfill_wp_blog_images.php` — fills `image` for imported rows (PHP's curl has no CA bundle on this XAMPP, so it uses `curl.exe`). The first `--commit` run inserted the rows but every image download failed (SSL), hence this script.
- `docs/backups/pre-import_tbl_blog_category_seo.sql` — pre-import backup of the three tables.

### Verification (actually run)
- Original 10 `tbl_blog` rows, 5 categories and 15 `tbl_seo` rows compared with the backup: **0 differences**.
- `/`, `/blog` and `/blog/<slug>` return 200 on `localhost:8000`.
- `php artisan test`: **29 failed / 4 passed — not caused by this change.** The tests connect to MySQL database `apca_india`, which does not exist locally (local DB is `apcaindia`). Not investigated further.

### Risks / follow-ups
- 239 posts are hidden (`status=0`); review and publish in the admin. 
- 175 of the new `tbl_seo` blog rows have an empty title (no Rank Math title in WP). Existing admin-created rows behave the same; a fallback to the post title is a possible improvement (not done — not requested).
- 2 posts reference images inline from the old WP uploads URL (not rewritten).
- 12 featured images are `.webp`; the admin uploader only accepts jpg/png, but displaying them works.
- Images (95 MB) are runtime content, not code.

### Deployment / rollback
- Production has the same schema, so the importer can be re-run there (it skips existing slugs). Run the dry run first and take a backup.
- Rollback (local): restore `docs/backups/pre-import_tbl_blog_category_seo.sql`, and delete files in `public/assets/upload/blog/` listed after the original 10.
- The scratch DB `apca_blog_wp_scratch` is the importer's source; drop it when no longer needed.

## Part C — Meta tags now rendered (code change)
- **Problem:** `header.blade.php`, `header-home.blade.php`, `header-fixed.blade.php` looked up `tbl_seo` but never printed it; `<title>APCA</title>` was hard-coded, so no `tbl_seo` data (existing, imported blog metas, sheet rows) reached the pages.
- **Change:** each header now outputs `<title>` (falls back to `APCA` when empty) and `<meta name="description">` / `<meta name="keywords">` only when non-empty. Values are Blade-escaped.
- **Impact:** page titles change site-wide wherever a `tbl_seo` row exists; pages without a row (e.g. `/about-us`) are unchanged.
- **Verified:** `/`, `/faq`, `/bangalore`, a course page and an imported blog post show the expected title + description.
- **Rollback:** restore the single `<title>APCA</title>` line in the three headers.
